# 큐브 타임어택

3×3 큐브를 무작위로 섞고, 직접 돌려 맞추고, 걸린 시간을 재는 브라우저 게임이에요.
설치 없이 `index.html` 하나만 브라우저로 열면 바로 플레이할 수 있어요.

## 기능

- **섞기**: 입문(3회) · 쉬움(6회) · 보통(12회) · 완전(25회) 중에서 골라 무작위로 섞어요.
- **타이머**: 섞은 뒤 첫 회전부터 재기 시작해서, 큐브가 완성되는 순간 멈춰요. 1/100초 단위로 표시돼요.
- **완성시키기 / 힌트**: 자동으로 맞추거나 다음 한 수를 알려 줘요. 둘 중 하나를 쓴 풀이는 최고 기록에 올라가지 않아요.
- **AI 대전**: 쉬움 · 보통 · 어려움 · 마스터 네 난이도가 있어요. 같은 섞기로 동시에 출발해서 먼저 완성하는 쪽이 이겨요.
- **기록**: 섞기 강도별 최고 기록, 최근 5회 평균(ao5), 난이도별 전적을 브라우저에 저장해요.

## 조작법

| 동작 | 방법 |
|---|---|
| 줄 돌리기 | 스티커를 끌기, 또는 회전 버튼 |
| 시점 돌리기 | 빈 곳을 끌거나 마우스 오른쪽 버튼으로 끌기 (각도 제한 없음) |
| 면 회전 키 | `U` `D` `L` `R` `F` `B`, 가운데 줄 `M` `E` `S`, `Shift` + 키 = 반대 방향 |
| 시점 키 | `←` `→` `↑` `↓`, 눕히기 `Z`, 큐브 기호 `X` `Y` `Z` (`Shift` = 반대), 기본 시점 `V` |

면 이름은 **지금 화면 기준**이에요. `U`는 화면 위쪽 면, `F`는 앞쪽 면, `R`은 오른쪽 면을 돌려요.

## AI 방식

AI는 섞인 순서를 거꾸로 되짚어서 맞춰요. 난이도가 낮을수록 손이 느리고, 방향을 헷갈리거나 오래 고민하는 일이 잦아요.

## 기술

- [three.js](https://threejs.org/) r128 (CDN)로 3D 큐브를 그려요.
- 빌드 과정이 없는 HTML 파일 하나로 되어 있어요.
